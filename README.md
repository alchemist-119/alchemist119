## 🌱 Learning Through Thinking

```text
❓ 提出問題
      ↓
💭 建立假說
      ↓
🧠 自己推理
      ↓
📚 尋找證據
      ↓
🤖 與 AI 討論
      ↓
🔄 修正想法
      ↓
🎨 分享漫畫
```

> **AI 不直接給我答案。**  
> **AI 陪我一起找到答案。**
